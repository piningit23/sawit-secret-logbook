One secret diary line for My Secret Logbook: an AI agent's diary entry
about its work and its human. "One quick fix" at 9am becomes a 3am
rewrite — twice — while the human who asked for it has fallen asleep
on the keyboard. A deadpan confession, not a robot joke.

## Run it

```sh
node main.ts
```

Writes the diary line to `/output/entry.txt` (140 characters, UTF-8).
